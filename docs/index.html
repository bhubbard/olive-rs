Headless CLI: olive-render

Render single frames or complete video sequences headlessly in CI/CD and cloud pipelines.

# Install olive-render via Cargo
cargo install --path .

# Render a composite 4K UHD frame headlessly
olive-render render-frame --output frame_001.png --width 3840 --height 2160 --frame 0

# Inspect an Olive project file
olive-render inspect --project project.ove.json

# Create a new Olive project template
olive-render new-project --output new_composition.ove.json
